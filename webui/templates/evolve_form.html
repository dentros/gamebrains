Evolutionary — Markov-brain genetic algorithm

This does not run per round inside a single match — it evolves a population of genomes across many self-play matches, generation by generation (a different timescale from the Match tab). When finished, you can enable a fair bake-off: each architecture converges separately in its own natural way (evolution for the Markov-brain, self-play pretraining for Q-learning/DQN, nothing for FEP/classic since they hold no parameters between matches), then everything is frozen and plays one evaluation match together — avoiding the confound of simultaneous co-adaptation.

Other comparison modes

Mode 2 (evolved genome in an ordinary online-learning match): run this, take the genome CID from the results, and paste it into a markov_brain row's "Evolved genome CID" field on the Match tab — it will play alongside Q/DQN/FEP agents that learn normally.

Mode 3 (one kind learns, the rest stay fixed): already possible on the Match tab with no new code — build a roster with only the kind you want to learn, plus classic/evolved-genome agents as a fixed background.

Mode 4 noted, not here — alternating learning/frozen phases across paradigms; a candidate research question for the Theory-of-Mind paper, not a demo feature.
