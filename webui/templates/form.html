Game

Sets how much cooperating is worth. Needs 1/n < MPCR < 1 (a genuine social dilemma). Blank picks a safe default automatically.
Congestion family

Every field below is optional. Leave it blank to keep whatever the chosen preset uses, which for the published ones is the configuration the papers actually ran.

At 2 a single simultaneous move decides the episode, the ballistic case. At 3 or more there is an intermediate cell, so an agent's approach is visible before it commits and movement itself can act as a signal.
Dividing by n keeps the penalty independent of how many actually collided; dividing by k is literal Rosenthal congestion.
0 is Type-A, positions only. 1 is Type-B, which also shows who arrived last episode and is what makes turn-taking learnable. Each extra episode multiplies the state space by 2^n, so this grows fast.
Ends an episode when nobody has arrived in time. Needed because agents that all hold back would otherwise never finish. A capped episode is recorded with no winner, which is a real outcome.

The published main rule keeps universal collision at exactly zero, so total non-coordination cannot register as partial success. The published k-variant deliberately does not, since r/k with everyone arriving simply yields r/n.
