Move one thing, watch everything

Pick a parameter and a range. Each value becomes its own experiment, they run at the same time across this machine's cores, and every measure the platform computes is drawn against the parameter as the runs land. Each one is recorded in the ledger like any other match, so the answer is queryable afterwards rather than only visible here.

One worker per core is deliberately not offered. The spare core is what keeps this page answering while the sweep runs, and a sweep you cannot watch is a batch job. Seeds are the honest part: three runs per value show whether a difference between values is larger than the difference between seeds.
